## Server Actions in React 19

**Server Actions** are one of the most revolutionary features in the React 19 (and Next.js App Router) ecosystem. They allow you to **write functions that run exclusively on the server**, but can be called directly from client components (_Client Components_) as well as server components (_Server Components_) without needing to manually build API endpoints (like REST or GraphQL routes).

### Why Are Server Actions So Helpful?

1. **No API Boilerplate**: You no longer need to create `route.ts` or `controller` files, configure CORS, and then call `fetch()` on the client side just to save data to a database.
2. **Built-in Security**: The code inside a Server Action is guaranteed to never leak to the browser (safe for API secrets, direct database interactions, etc.).
3. **Progressive Enhancement**: When attached to a `<form action={...}>` tag, these functions can still work even if the user's browser JavaScript is disabled or hasn't finished loading (_hydrated_).

---

### How to Use Server Actions

You define a Server Action by adding the `"use server"` directive at the beginning of a function or at the top of a file.

#### 1. The Old Way (Requires API Route)
```tsx
// ❌ OLD WAY (React 18 / Traditional)
// Client has to call an API
const handleSubmit = async (e) => {
  e.preventDefault();
  const res = await fetch("/api/users", {
    method: "POST",
    body: JSON.stringify({ name: "Ubay" })
  });
  const data = await res.json();
}
```

#### 2. The New Way with Server Actions
Here is an example of how we directly mutate data in the database from a function that can be called by a form.

```tsx
// ✅ NEW WAY: actions.ts (Separate file for Server Actions)
"use server"; // Indicates all functions in this file run on the server

import { db } from "@/lib/db";
import { revalidatePath } from "next/cache";

export async function createPost(formData: FormData) {
  // 1. Get data from form
  const title = formData.get("title");
  const content = formData.get("content");
  
  // 2. Save directly to database (secure, runs on server)
  await db.post.create({
    data: { title, content }
  });
  
  // 3. Tell Next.js to revalidate the page so fresh data appears
  revalidatePath("/posts");
}
```

Then call the action in your component:

```tsx
// Client or Server Component
import { createPost } from "./actions";

export default function PostForm() {
  return (
    // React 19 supports form actions accepting async functions!
    <form action={createPost} className="flex flex-col gap-4">
      <input type="text" name="title" placeholder="Post Title" />
      <textarea name="content" placeholder="Post Content" />
      <button type="submit">Save to Database</button>
    </form>
  );
}
```

### Combining Server Actions with `useActionState`

In React 19, there is a new hook called `useActionState` which pairs perfectly with Server Actions to handle state (loading) and error or success messages from the server.

```tsx
"use client";
import { useActionState } from "react";
// Assuming createPost returns { error: string } or { success: string }
import { createPost } from "./actions";

export default function EnhancedForm() {
  const [state, formAction, isPending] = useActionState(createPost, null);

  return (
    <form action={formAction} className="flex flex-col gap-2">
      <input type="text" name="title" disabled={isPending} />
      <button type="submit" disabled={isPending}>
        {isPending ? "Saving..." : "Submit"}
      </button>

      {/* Displaying message from server */}
      {state?.error && <p className="text-red-500">{state.error}</p>}
      {state?.success && <p className="text-green-500">{state.success}</p>}
    </form>
  );
}
```

**Conclusion:**
Server Actions eliminate the complexity of manually creating APIs for simple operations (like form submissions or data mutations). Just create a function on the server, add `"use server"`, and call it from your components!
