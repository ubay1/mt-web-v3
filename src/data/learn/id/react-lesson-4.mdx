## Fitur Baru di React 19

React 19 membawa banyak perubahan besar yang membuat penulisan kode menjadi lebih ringkas dan berpusat pada **Server Components** serta **Actions**. Rilis ini juga menghentikan penggunaan beberapa API lama (seperti `useMemo` dan `useCallback` yang sekarang sebagian besar digantikan oleh *React Compiler*).

<React19Demo />

Berikut adalah fitur-fitur kunci di React 19 yang perlu kamu ketahui:

### 1. Actions & `useActionState`

Dulu, untuk menangani pengiriman form (form submission), kamu harus menggunakan `e.preventDefault()`, mengelola *state loading*, *error*, dan *data* secara manual. Di React 19, fitur ini dibangun secara bawaan (*native*) menggunakan **Actions**.

```jsx
import { useActionState } from 'react';

async function ping() {
  const { data, error } = await fetch('/api/ping').then(res => res.json());
  if (error) return { error };
  return { success: true, data };
}

function FormPing() {
  const [state, submitAction, isPending] = useActionState(ping, { error: null });

  return (
    <form action={submitAction} className='p-4 flex flex-col gap-2 w-1/2'>
      <label htmlFor="name">Name</label>
      <input type="text" name="name" disabled={isPending} className="bg-white text-black p-2" placeholder='masukan nama...' />
      <button type="submit" disabled={isPending} className='bg-accent text-black p-2'>
        {isPending ? 'Menyimpan...' : 'Simpan'}
      </button>
      {state.error && <p className="error text-red-500">{state.error}</p>}
      {state.success && <p className="text-green-500">{state.data}</p>}
    </form>
  );
}

export default FormPing;
```

### 2. `useFormStatus`

Hook baru ini memungkinkan komponen anak (child) di dalam sebuah `<form>` untuk mengetahui status form tersebut tanpa perlu menerima *props* tambahan.

```jsx
import { useFormStatus } from 'react-dom';

function SubmitButton() {
  const { pending } = useFormStatus();

  return (
    <button type="submit" disabled={pending} className='bg-accent text-black p-2'>
      {pending ? 'Menyimpan...' : 'Simpan'}
    </button>
  );
}
```

---

### 3. Hook `use`

Hook `use` adalah cara baru untuk membaca sumber daya asinkron (*Promises*) atau *Context* secara langsung, bahkan di dalam *conditional statement* (seperti `if`), sesuatu yang sebelumnya dilarang dalam React Hooks!

```jsx
'use client'
import { use, Suspense, useState } from 'react';

function MessageComponent({ promise }) {
  const message = use(promise);
  return <p className="text-green-500 font-bold">{message.data}</p>;
}
```

> **Catatan Penting:** Hook `use` harus digabungkan dengan `<Suspense>`. Saat *Promise* sedang berjalan (*pending*), komponen akan "ditangguhkan" (suspend) dan menampilkan antarmuka *loading* dari `<Suspense>`.

---

### 4. React Server Components (RSC)

Meskipun diperkenalkan sebelumnya (bersama Next.js), React 19 mengukuhkan *Server Components* secara *native*. Secara default, jika kamu menggunakan *framework* seperti Next.js, komponen dirender di server.

- **Kelebihan**: Mengurangi ukuran *bundle* JavaScript yang dikirim ke client (karena *dependencies* tetap di server) dan mempercepat akses data (bisa langsung akses database di komponen).
- Komponen yang butuh interaksi (seperti *onClick* atau *useState*) harus ditandai dengan direktif `"use client"`.

---

### 5. `ref` sebagai Prop Biasa

Sebelumnya, jika kamu ingin meneruskan `ref` ke komponen kustom, kamu wajib membungkusnya dengan `forwardRef`. Di React 19, `ref` menjadi *prop* biasa!

```jsx
// DULU (React 18):
const MyInput = forwardRef((props, ref) => <input ref={ref} {...props} />);

// SEKARANG (React 19):
function MyInput({ ref, ...props }) {
  return <input ref={ref} {...props} />
}
```

---

### 6. `<Context>` sebagai Provider

Tidak perlu lagi menulis `<ThemeContext.Provider>`. Di React 19, kamu cukup menggunakan objek *Context* langsung sebagai tag.

```jsx
const ThemeContext = createContext('light');

function App() {
  return (
    <ThemeContext value="dark">
      <Main />
    </ThemeContext>
  );
}
```

## Kesimpulan

React 19 sangat fokus pada **Penyederhanaan** (menghilangkan `forwardRef`, `.Provider`, `useMemo`/React Compiler) dan **Akselerasi Data Fetching/Form** (`useActionState`, `use`, *Server Components*).
