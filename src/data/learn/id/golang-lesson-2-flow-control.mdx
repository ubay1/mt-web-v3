## 1. Pengulangan `for`

Jika kamu ingin **mengulang sesuatu berkali-kali** di Golang, kamu akan menggunakan `for`. 

Sebenarnya, Golang hanya memiliki **satu jenis perintah pengulangan** saja, yaitu `for`. Tidak ada `while` atau `do-while` seperti di bahasa pemrograman lain. Tapi jangan khawatir, `for` di Go sangat fleksibel.

### Struktur Dasar `for`

Sama seperti bahasa C atau Java, `for` di Go memiliki **3 komponen utama** yang dipisahkan oleh titik koma (`;`). Namun bedanya, di Go kamu **tidak perlu membungkusnya dengan tanda kurung `()`**.

```go
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

**Penjelasan Komponen:**
1. `i := 0` *(Init Statement)*: Dijalankan tepat **sekali** sebelum perulangan dimulai.
2. `i < 5` *(Condition)*: Diperiksa sebelum **setiap putaran**. Jika `false`, perulangan langsung berhenti.
3. `i++` *(Post Statement)*: Dijalankan di **akhir** setiap putaran.

> [!IMPORTANT]
> **Wajib Menggunakan Kurung Kurawal `{}`**
> Walaupun bagian kondisinya tidak dibungkus kurung bulat `()`, blok kode yang akan dieksekusi **wajib** menggunakan kurung kurawal `{}`.

### Simulasi `for` Loop

Agar lebih terbayang, mari kita lihat simulasi perulangan berikut:

```go
sum := 0
for i := 0; i < 4; i++ {
  sum += i
}
fmt.Println(sum) // Hasilnya adalah 6
```

Mengapa hasilnya 6? Prosesnya berjalan seperti ini:

| Iterasi ke- | Nilai `i` saat ini | Operasi `sum + i` | Nilai `sum` menjadi |
| :---: | :---: | :--- | :---: |
| 1 | `0` | `0 + 0` | 0 |
| 2 | `1` | `0 + 1` | 1 |
| 3 | `2` | `1 + 2` | 3 |
| 4 | `3` | `3 + 3` | 6 |

## 2. `for` Sebagai Pengganti `while`

Tahukah kamu? Bagian awal (*init*) dan akhir (*post*) pada blok `for` sebenarnya tidak wajib ditulis. 

Jika kamu menghapusnya, `for` di Go akan berperilaku **persis seperti `while` loop** pada bahasa pemrograman lain!

```go
// Cara Go (menggunakan for)
i := 0
for i < 5 {
    fmt.Println(i)
    i++
}
```

Sebagai perbandingan di JavaScript:
```js
// Cara JavaScript (menggunakan while)
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
```

Sangat bersih dan minimalis, bukan?

## 3. Percabangan Dasar: `if`

Perintah `if` digunakan jika kita hanya ingin menjalankan suatu baris kode saat suatu kondisi terpenuhi (bernilai `true`).

Sama seperti `for`, penulisan `if` di Go juga **tidak memerlukan tanda kurung bulat `()`**, namun **tetap wajib menggunakan kurung kurawal `{}`**.

```go
x := 10

if x > 5 {
    fmt.Println("x lebih besar dari 5")
}
```

---

## 4. `if` dengan Short Statement

Ada satu fitur unik dan sangat berguna di Go: Kamu bisa menyisipkan sebuah **perintah singkat (*short statement*)** tepat sebelum kondisi diperiksa!

Ini sangat sering digunakan untuk mendeklarasikan variabel yang *hanya dibutuhkan di dalam blok `if` tersebut*.

```go
if v := 10; v > 5 {
    fmt.Println(v)
}
```

**Bagaimana cara kerjanya?**
1. Perintah `v := 10` dijalankan lebih dulu.
2. Kondisi `v > 5` diperiksa.
3. Karena bernilai benar, perintah `fmt.Println(v)` dieksekusi.

> [!WARNING]
> **Scope (Ruang Lingkup) Variabel**
> Variabel `v` yang dibuat pada blok `if` di atas **hanya akan ada dan bisa dipakai di dalam blok `if` tersebut**. Jika kamu mencoba memanggilnya di luar `if`, program akan error!
>
> ```go
> if v := 10; v > 5 {
>     fmt.Println(v) // ✅ Aman
> }
> fmt.Println(v) // ❌ ERROR: undefined: v
> ```

## 5. Menggunakan `switch`

Ketika kamu dihadapkan pada terlalu banyak rantai `if - else if - else if`, kode akan terlihat kotor. Solusinya adalah menggunakan **`switch`**.

Go mengevaluasi `switch` dari atas ke bawah, dan akan berhenti seketika saat menemukan satu `case` yang cocok.

```go
nilai := 2

switch nilai {
case 1:
    fmt.Println("Satu")
case 2:
    fmt.Println("Dua") // Go akan menjalankan baris ini
case 3:
    fmt.Println("Tiga")
}
```

> [!NOTE]
> **Tidak Butuh `break`!**
> Bagi kamu yang pernah belajar C, Java, atau Javascript: Di Go kamu **tidak perlu menulis kata kunci `break`** di setiap akhir `case`. Go sudah cukup pintar untuk langsung keluar dari blok `switch` setelah mengeksekusi *case* yang benar.

### `switch` Tanpa Kondisi

Tahukah kamu bahwa `switch` bisa digunakan tanpa harus membandingkan sebuah nilai awal? Jika kamu mengosongkan kondisinya, ia setara dengan menulis `switch true`.

Gaya ini sangat disukai programmer Go karena merupakan **cara yang jauh lebih rapi dan bersih** dibandingkan merangkai banyak kondisi `if - else`.

```go
score := 7

switch {
case score < 6:
    fmt.Println("Kurang")
case score < 8:
    fmt.Println("Cukup") // Akan tercetak karena score (7) kurang dari 8
default:
    fmt.Println("Baik")
}
```

## 6. Penundaan Eksekusi (`defer`)

Pernahkah kamu ingin mengeksekusi sebuah kode nanti saja, **tepat sebelum sebuah fungsi berakhir**? Di Golang, ada sintaks khusus untuk melakukan itu: **`defer`**.

```go
func main() {
    defer fmt.Println("Dunia") // Ditahan!
    fmt.Println("Halo")
}
```

**Output:**
```
Halo
Dunia
```

Meskipun perintah `Println("Dunia")` ditulis di atas, ia dieksekusi di akhir fungsi `main()`. Fitur ini biasanya sangat berguna ketika kita membuka koneksi database atau membaca file, dan kita ingin memastikan kita menutupnya (*close*) di akhir operasi.

### Bertumpuknya `defer` (Multiple Defer)

Lalu bagaimana jika kita menulis beberapa `defer` di dalam satu fungsi?

Jika ada lebih dari satu fungsi yang di-*defer*, maka sistem kerjanya memakai prinsip **LIFO (Last In, First Out)** alias tumpukan. **Defer yang ditulis paling bawah (paling terakhir), akan dieksekusi paling awal!**

```go
func main() {
	defer fmt.Println("Satu")
	defer fmt.Println("Dua")
	defer fmt.Println("Tiga")

	fmt.Println("Mulai...")
}
```

**Output:**
```
Mulai...
Tiga
Dua
Satu
```

Itu dia! Kamu sudah memegang kendali penuh atas alur logika programmu. Di bab selanjutnya, bersiaplah untuk pusing sedikit karena kita akan masuk ke **Tipe Data Lanjutan** seperti Pointer dan Struct!
