## Server Actions di React 19

**Server Actions** adalah salah satu fitur paling revolusioner di ekosistem React 19 (dan Next.js App Router). Fitur ini memungkinkan kamu untuk **menulis fungsi yang berjalan eksklusif di server**, tetapi dapat dipanggil langsung dari komponen klien (_Client Components_) maupun komponen server (_Server Components_) tanpa perlu membuat _endpoint_ API (seperti rute REST atau GraphQL) secara manual.

### Mengapa Server Actions Sangat Membantu?

1. **Tanpa API Boilerplate**: Kamu tidak perlu lagi membuat file `route.ts` atau `controller`, mengatur CORS, lalu memanggil `fetch()` di sisi klien hanya untuk menyimpan data ke _database_.
2. **Keamanan Bawaan**: Kode di dalam Server Action dijamin tidak akan pernah bocor ke browser (aman untuk rahasia API, interaksi _database_ langsung, dsb).
3. **Progressive Enhancement**: Jika disematkan pada tag `<form action={...}>`, fungsi ini bisa tetap bekerja meskipun JavaScript di browser pengguna sedang dimatikan atau belum selesai dimuat (_hydrated_).

---

### Cara Menggunakan Server Actions

Kamu mendefinisikan sebuah Server Action dengan menambahkan direktif `"use server"` di awal fungsi atau di bagian atas file.

#### 1. Cara Lama (Membutuhkan API Route)

```tsx
// ❌ CARA LAMA (React 18 / Tradisional)
// Klien harus memanggil API
const handleSubmit = async (e) => {
  e.preventDefault();
  const res = await fetch("/api/users", {
    method: "POST",
    body: JSON.stringify({ name: "Ubay" }),
  });
  const data = await res.json();
};
```

#### 2. Cara Baru dengan Server Action

Ini adalah contoh bagaimana kita langsung memproses form dan mengembalikan respon dari server tanpa membuat API route terpisah.

```tsx
//  actions.ts (File terpisah untuk Server Actions)
"use server"; // Menandakan semua fungsi di file ini berjalan di server

export async function myServerAction(prevState: any, formData: FormData) {
  // Simulasi waktu proses di server (delay 1.5 detik)
  await new Promise((resolve) => setTimeout(resolve, 1500));

  const name = formData.get("name")?.toString();

  // Validasi input
  if (!name || name.trim() === "") {
    return { error: "Nama tidak boleh kosong!", success: false };
  }

  // Simulasi fatal error (Uncaught Exception)
  if (name.toLowerCase() === "crash") {
    throw new Error("💥 BAM! Server mengalami fatal error (Exception).");
  }

  // Simulasi jika terjadi error logika bisnis di server
  if (name.toLowerCase() === "error") {
    return { error: "Ups! Simulasi error logika dari server.", success: false };
  }

  // Berhasil
  return {
    message: `Halo ${name}, Server Action berhasil memproses datamu secara langsung tanpa API Route!`,
    success: true,
  };
}
```

### Menggabungkan Server Actions dengan `useActionState` & `useFormStatus`

Di React 19, hook `useActionState` sangat cocok disandingkan dengan Server Actions untuk menangani status dan pesan balasan dari server. Digabungkan dengan `useFormStatus`, kita bisa dengan mudah membuat tombol loading.

```tsx
// Komponen Klien (page.tsx)
"use client";

import { useActionState } from "react";
import { useFormStatus } from "react-dom";
import { myServerAction } from "./actions";

// Komponen tombol submit yang otomatis mendeteksi status "loading" form
function SubmitButton() {
  const { pending } = useFormStatus();

  return (
    <button type="submit" disabled={pending}>
      {pending ? "Memproses di Server..." : "Eksekusi Server Action"}
    </button>
  );
}

export default function TestActionPage() {
  // useActionState menggantikan useFormState di React 19
  // Menerima (actionFunction, initial_state)
  const [state, formAction] = useActionState(myServerAction, null);

  return (
    // Perhatikan bahwa kita melewatkan formAction ke properti action form
    <form action={formAction} className="flex flex-col gap-6">
      <input
        type="text"
        name="name"
        placeholder="Ketik namamu (Coba ketik 'error' atau 'crash')..."
      />

      <SubmitButton />

      {/* Menampilkan pesan error dari server */}
      {state?.error && <p className="text-red-500">{state.error}</p>}

      {/* Menampilkan pesan sukses dari server */}
      {state?.success && <p className="text-green-500">{state.message}</p>}
    </form>
  );
}
```

**Kesimpulan:**
Server Actions menghapus kerumitan membuat API manual untuk operasi sederhana (seperti form _submit_ atau mutasi data). Cukup buat fungsi di server, berikan `"use server"`, dan panggil dari komponenmu!
